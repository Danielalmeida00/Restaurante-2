🚀 COMO RODAR — RESUMO RÁPIDO
─────────────────────────────────────────────────────────────────────────────

BACKEND (Terminal 1)
─────────────────────
cd weekflow/backend

# Windows
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

# Mac/Linux
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python3 app.py

Esperado: "🚀 WeekFlow Backend rodando em http://localhost:5000"

FRONTEND (Terminal 2)
─────────────────────
cd weekflow/frontend

npm install
npm run dev

Esperado: "➜  Local:   http://localhost:3000/"

ABRIR NO NAVEGADOR
──────────────────
http://localhost:3000

📋 ENDPOINTS DA API
─────────────────────────────────────────────────────────────────────────────

GET /api/tasks
└─ Retorna todas as tarefas em JSON
   Resposta: [{"id": 1, "dia": "Segunda-feira", "hora": "09:00", ...}, ...]

POST /api/tasks
└─ Cria uma nova tarefa
   Body: {"dia": "Segunda-feira", "hora": "09:00", "dever": "Estudar"}
   Resposta: {"msg": "Tarefa criada!", "task": {...}}

DELETE /api/tasks/{id}
└─ Remove uma tarefa pelo ID
   Resposta: {"msg": "Tarefa removida!"}

GET /api/health
└─ Verifica status da API
   Resposta: {"status": "online", "message": "..."}

🐛 TROUBLESHOOTING
─────────────────────────────────────────────────────────────────────────────

Problema: "Connection refused"
Solução: Verifique se backend está rodando em localhost:5000

Problema: "npm: command not found"
Solução: Instale Node.js em https://nodejs.org

Problema: "ModuleNotFoundError: No module named 'flask'"
Solução: pip install -r backend/requirements.txt

Problema: Banco não foi criado
Solução: Rode python app.py — será criado weekflow.db

Problema: Porta 3000 em uso
Solução: npm run dev -- --port 3001
