COMO USAR:
==========

1. LEIA OS GUIAS (5 minutos):
   - Comece com COMECE_AQUI.md
   - Depois GUIA_RAPIDO.md
   - Se tiver dúvidas, consulte GUIA_AVANCADO.md

2. INSTALE O PROJETO:
   cd sabor-da-vila
   npm install

3. EXECUTE LOCALMENTE:
   npm run dev
   # Abrirá em http://localhost:5173

4. CUSTOMIZE COM SEUS DADOS:
   - Edite src/data/menu.js
   - Adicione seus pratos
   - Atualize número WhatsApp
   - Substitua imagens

5. FAÇA DEPLOY:
   npm run build
   # Upload em Netlify ou Vercel
